# Raphael Medeiros

**Principal Software Engineer & Software Architect**

I'm a software engineer and architect based in Brazil, specialising in Java, Spring Boot, distributed systems and platform engineering.

At the Federal University of Rio Grande do Norte (UFRN), I work with engineering teams on institutional platforms, shared APIs, identity and access management, observability and the modernisation of long-lived systems. My contributions span architecture, implementation, maintenance and technical guidance.

At E50 I.T., I build [Liten](https://liten.to/), a production SaaS for links, public pages and analytics. My work covers product architecture, backend development, security, billing and operations, including governed MCP access.

## Engineering focus

- Java and Spring Boot backends, REST APIs and distributed systems.
- Identity and security: OAuth, SSO, access control and audit.
- Platform engineering: Docker, Kubernetes, CI/CD and observability.
- AI-assisted software delivery with automated tests, security controls and human review.
